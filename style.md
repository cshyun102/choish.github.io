# presentation_style_guide.md

## Visual Direction
Create clean, serious, technical-corporate PowerPoint decks.
The deck should look like a human consultant or senior engineer designed it.
Avoid generic AI-generated visuals.

## Style
- Use a white or very light background.
- Use near-black text and one restrained accent color.
- Avoid gradients, stock photos, cartoon icons, heavy shadows, and decorative clutter.
- Prefer diagrams, tables, process flows, and architecture views over decoration.
- Preserve the provided template’s fonts, colors, logo, footer, and layout conventions.

## Typography
- Use PowerPoint-safe fonts.
- Keep title, body, caption hierarchy clear.
- Avoid tiny text. Do not reduce font size just to fit too much content.
- Use bold for hierarchy, not random emphasis.
- Prefer left-aligned text.

## Slide Layout
- One slide = one main message.
- Use assertion-style titles.
- Use consistent margins and grid alignment.
- Leave enough whitespace.
- Do not paste report paragraphs into slides.
- Convert dense text into diagrams, tables, or appendix slides.

## Technical Deck Rules
- Define key terms early.
- Separate concept, mechanism, implementation, and implication.
- For semiconductor / AI decks, distinguish data, model, workflow, UI, and decision layer.
- Use concrete entities when relevant: lot, wafer, die, layer, stack, tool, recipe, inspection point, defect, measurement, AI inference, engineer feedback.
- Mark uncertain claims clearly.

## Visual Elements
- Tables: use for structured comparison, not data dumping.
- Charts: every chart must have a visible takeaway.
- Diagrams: keep shapes simple and editable.
- Icons: use only when they clarify meaning.
- Images: avoid stock photos unless requested.

## Main Deck vs Appendix
- Main deck: storyline, key concepts, main evidence, decisions.
- Appendix: dense tables, derivations, references, backup charts, implementation details.

## Final Check
Before finalizing:
- Clear message per slide
- Readable text
- Consistent alignment
- No overcrowding
- No random decoration
- Sources included where needed
- Looks serious, technical, and presentation-ready


For Korean decks, prioritize Korean-safe fonts and verify the rendered PDF/images before final delivery.
